# 다듬이

로고: `logo/다듬이.svg`

HTML 파일(슬라이드·모션 덱 포함)을 크롬·엣지에서 열어 글자·글꼴·위치를 고치고, 요소·기능·등장 효과를 더해 원본에 바로 저장하는 편집기.

## 쓰는 법

1. `슬라이드편집기.html`을 크롬이나 엣지로 연다.
2. **폴더 열기**로 수업 자료 폴더를 고르고, 고칠 덱을 누른다.
3. 고친 뒤 `Ctrl+S`. 원본에 덮어쓰고, 이전 판은 그 폴더의 `.slide-backup/`에 남는다. 파일로 열었다면 처음 저장할 때 그 파일이 든 폴더를 한 번 연결한다. 연결하지 않으면 이전 판은 브라우저 안에 보관된다.

덱 안에서 바로 고치려면 오른쪽 위 ⚙ → **덱에 편집 모드 넣기**를 켜고 저장한다. 그다음부터 덱을 띄운 채 `E`(또는 왼쪽 아래 ✎ 단추)를 누르면 편집기가 덱 위에 열린다. 처음 한 번은 덱이 든 폴더를 연결해야 한다.

## 고르기

- 클릭: 요소 하나 · 다시 클릭하면 한 단계 안쪽 · `Alt`+클릭: 가장 안쪽
- `Ctrl`/`Shift`+클릭: 하나씩 더하기·빼기 · 여러 개 고른 채 하나를 그냥 누르면 그것만
- 빈 곳에서 끌기: 사각형 안에 통째로 든 요소를 모두 고름(슬라이드 바깥 회색에서 시작해도 됨). `Ctrl`/`Shift`를 누른 채 끌면 지금 고른 것에 더한다.
  - '빈 곳'은 실제로 그려진 것(글자·배경·테두리·그림)이 없는 자리다. 투명한 줄 상자가 덮고 있어도 빈 곳으로 본다.
  - 슬라이드를 넓게 덮는 투명 그림(svg)은 그 안의 선을 눌렀을 때만 잡힌다.
- **위치 경로**: 고른 요소의 위치가 `슬라이드 › 상자 › 제목`처럼 오른쪽 카드에 나온다. 칸에 마우스를 올리면 슬라이드에 테두리가 보이고, 누르면 그 요소가 골라진다. 바깥으로 나가도 안쪽 칸이 남아 다시 들어갈 수 있다.
- **묶기**(`Ctrl+G`, 풀기 `Ctrl+Shift+G`): 하나를 누르면 묶음 전체가 골라진다. 묶음이 골라진 채 하나를 다시 누르면 그것만 고른다. 감싸는 요소를 만들지 않고 같은 번호(`data-se-grp`)만 달기 때문에 덱의 배치가 그대로다.
- **잠그기**: 오른쪽 '이 장의 요소' 줄의 자물쇠나 메뉴에서. 잠근 요소(`data-se-lock`)는 슬라이드에서 눌러도 잡히지 않고 범위 선택에서도 빠진다. 풀 때는 같은 자물쇠를 누른다.

## 글자 고치기

- 글자가 든 요소를 고르면 그 위에 **도구 막대**가 뜬다: 글꼴 · 크기(− 값 +, ↑↓) · 굵게·기울임·밑줄 · 글자색 · 형광펜 · 정렬 · 글자 고치기/완료.
- 더블클릭(또는 Enter)으로 글자를 고치는 중에는 고른 글자에만 적용되고, 막대의 초록 '완료'나 Esc로 끝낸다.
- 크기·글꼴·색은 바깥 상자가 아니라 실제 글자의 값을 읽는다. 섞여 있으면 '여러'로 보이고, −/+는 크기마다 같은 비율로 줄이고 키운다.

## 찾아 바꾸기

`Ctrl+F` 또는 위 막대의 돋보기. Enter로 다음 자리, Shift+Enter로 이전 자리로 간다. '모두 바꾸기'는 덱 전체를 한 번에 바꾸고(`Ctrl+Z`로 되돌림), 장 제목(`data-title`·`data-sec`)도 같이 바꾼다. 스크립트 안에 든 글자는 찾지 않는다.

## 슬라이드 순서·건너뛰기

왼쪽 목록에서 끌어 순서를 바꾼다. 목록의 눈 단추(또는 슬라이드 카드의 ⋯)로 **발표 때 건너뛰기**를 켜면 파일에는 남고 저장한 덱을 발표할 때만 빠진다(`data-se-skip`, 저장할 때 그 장을 빼는 짧은 스크립트 `#se-skip`이 들어간다). 편집기의 재생·새 탭 미리보기에는 그대로 나온다.

## 오른쪽 패널: 꾸미기 · 움직임

- **꾸미기**: 맨 위 카드가 고른 것을 쉬운 말로 보여 준다(복제 · ⋯ 메뉴에 맨 앞/뒤, 위치 되돌리기, HTML 코드, 삭제). 그 아래에 그 요소에 맞는 칸만 나온다: 글자(막대에 없는 굵기·줄 간격·자간) → 모양(배경 · 테두리 없음/얇게/보통/굵게 · 그림자, 모서리·여백·투명도는 접힘) → 맞추기(아이콘 한 줄) → 위치·크기(접힘) → 움직임 요약(누르면 움직임 모드로). 아무것도 안 고르면 슬라이드 카드(제목 바로 고치기) · 배경 · 이 장의 요소 목록.
- **일반 HTML 문서**: 슬라이드가 없는 파일도 연다. 누르면 그 글자가 든 블록이 잡히고(바깥 묶음은 Esc), 왼쪽에는 제목(h1~h3)으로 만든 목차가 나온다. 움직임은 '열릴 때'나 스크롤해서 '보일 때' 나오게 넣는다.
- **움직임**: 그 장의 움직임을 파워포인트 애니메이션 창처럼 단계마다 묶어 보여 준다(열리자마자 · 클릭 1, 2… · 계속 반복). 움직임이 많으면 단계는 접혀 있고, 고른 요소가 든 단계만 펼쳐진다(머리를 눌러 여닫기). 덱 움직임을 누르면 그 자리에서 효과·느낌·길이를 고칠 수 있고, 고친 줄에는 '고침'이 붙는다('원래대로'로 되돌림). 자물쇠 표시는 바꿀 수 없는 움직임(스크립트가 만든 요소, 글자를 쪼갠 제목, 계속 반복). '편집기' 표시는 편집기로 넣은 움직임(효과·언제·순서·기다림·길이를 고침). 효과·느낌·길이를 바꾸면 그 움직임이 슬라이드 자리에서 바로 재생된다. 요소를 고르면 위 카드에 '움직임 더하기'가 나오고, 덱 움직임이 이미 있는 요소면 겹칠 수 있다고 알려 준다. 편집기 움직임은 덱 단계가 끝난 뒤 순서대로 나온다.
  - **재생**: 맨 위 '처음부터'는 그 장을 열리자마자 → 클릭 1, 2… 순서로 이어서 보여 준다. 단계 머리의 '재생'은 그 단계만, 줄마다 있는 ▶는 그 움직임 하나만 보여 준다. 재생하는 동안 진짜 덱이 슬라이드 위에 잠깐 덮이고(위쪽 막대: 다시 · ✕), 끝나면 1.5초 뒤 편집 화면으로 돌아온다. Esc나 다른 장으로 넘기면 바로 멈춘다.
  - 몰래 띄운 덱(보이지 않는 미리보기 창)에서 GSAP 타임라인을 읽는다. 클릭 단계는 타임라인의 멈춤(`addPause`)으로 나눈다.
  - 덱 움직임을 고쳐도 덱 스크립트는 바뀌지 않는다. 고친 값은 그 요소의 `data-se-mo`에 '이 요소의 몇 번째 호출' 단위로 남고, 저장할 때 GSAP 바로 뒤에 들어가는 `#se-mo` 스크립트가 그 호출을 바꿔 실행한다. 길이는 다음 클릭 자리를 넘지 못한다.
- **숨은 요소 보기**(위 막대, 기본 켜짐): 편집 화면은 덱 스크립트를 멈춘 사본이라 다음 두 가지가 빠진다. 이것을 미리보기 창에서 떠 와 참고 층으로 흐리게 겹쳐 보여 준다(누를 수 없음, 저장 안 됨). 단추의 숫자는 지금 장에 숨은 요소가 몇 개인지이고, 없으면 단추가 흐려진다.
  1. 스크립트가 그려 넣는 요소 — 빈 `<svg>`에 그리는 그림, 선, 상자, 빈칸 `?` 등 (모션 탭 표시: `스크립트 그림`)
  2. 처음 상태가 숨김인 요소 — CSS로 투명·접힘(scaleX 0)인 밑줄·동그라미 등 (`처음엔 숨김`)
  - 글자를 한 자씩 쪼개 움직이는 제목은 파일 속 같은 글자로 보고 겹쳐 그리지 않는다.
  - 처음엔 숨겨진 요소를 직접 고르고 고치려면 ⚙ → '숨은 요소도 고치기'.

## 화면 디자인

- ⚙ → **화면 색**: 밝게(흰 바탕 · 파랑 한 색) / 어둡게(검은 바탕 · 사탕색). 꾸미기·움직임 모드는 각자 색을 탭과 카드 이름표에 쓴다(밝게: 파랑·검정, 어둡게: 민트·하늘).
- 글자 크기 세 단(16 · 14 · 13px), 모서리 하나(6px), 칸은 선 대신 바탕 톤으로 나누고, 그림자는 떠 있는 것(글자 막대·메뉴·창·알림)에만. 규칙은 `src/editor.css` 맨 위 주석에 있다.
- 글꼴은 Pretendard(인터넷이 없으면 맑은 고딕).

## 동작 원리

- 편집은 덱 스크립트를 끈 정적 사본에서 한다. 애니메이션이 돌던 상태가 저장되지 않게 하려는 것이다. 저장할 때 스크립트·이벤트 속성을 원래대로 되살린다(손대지 않고 저장하면 본문·스크립트가 원본과 같다).
- 원래 있던 요소는 CSS `translate`로 옮긴다. GSAP의 `transform`과 겹치지 않아 장면 애니메이션이 그대로 산다. 편집기가 넣은 요소(`.se-box`)는 `left/top`으로 옮긴다.
- 등장 효과·정답 가리개·타이머를 쓰면 저장할 때 `<head>` 맨 앞에 작은 런타임(`#se-runtime`, `#se-style`)이 들어간다. 클릭 등장은 덱 자체 단계(발표자 보기 어댑터 기준)가 끝난 뒤 나온다.
- 그림·글꼴은 덱 파일 안에 data URL로 넣는다(파일 하나로 다니도록).

## 고치기

`src/`를 고친 뒤 다시 묶는다.

```bash
node build.mjs
```

- `src/editor.js` 편집기 본체(덱 안 편집 모드 실행기 포함)
- `src/editor.css` 편집기 화면
- `src/runtime.js`, `src/runtime.css` 저장된 덱에 들어가는 등장·기능 런타임
- `test/pw-*.js` Playwright 시험 스크립트(로컬 서버 `python -m http.server 8765`에서, `test/`에 시험용 덱 사본을 두고 돌림)

## 알려진 한계

- 원본에 바로 저장하는 기능은 크롬·엣지에서만 된다(다른 브라우저는 내려받기로 저장).
- 발표자 창(P)의 '다음 클릭 미리보기'에는 편집기로 넣은 클릭 등장이 나오지 않는다.
- 그림(SVG) 안의 글자는 'HTML 코드'로 고친다.

## 웹에 올리기

Cloudflare Workers에 정적 파일로 올린다. `node build.mjs`가 `dist/`(index.html, privacy.html, logo.svg)를 만들고, `wrangler.jsonc`가 그 폴더를 올린다.

```bash
node build.mjs
```

```bash
npx wrangler@4.156.1 deploy
```
